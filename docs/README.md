# Documentation

## Owns

This directory contains architecture decisions, ownership rules, API contracts,
and platform-level product documentation.

## Put here

Document decisions that affect more than one application, deployment boundary,
or team. Keep implementation details close to the code they describe.

## Do not put here

Secrets, generated files, temporary notes, or source code. Application-specific
instructions belong beside the application in its README.

## Stop here

Update documentation when an ownership boundary or workflow changes. Do not
duplicate every code comment or component detail here.

See `architecture.md` for the frontend and backend ownership model.
