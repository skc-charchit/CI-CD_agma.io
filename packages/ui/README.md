# Shared UI

## Owns

Reusable design-system components, tokens, and accessibility patterns shared by
the company website and product frontends.

## Put here

Components that have more than one consumer and have a stable, product-neutral
API.

## Do not put here

Company-only page layouts, product-specific workflows, backend code, or one-off
visual experiments.

## Stop here

Promote a component here only after reuse is real or clearly required by the
platform. Keep single-use components in the owning frontend.
