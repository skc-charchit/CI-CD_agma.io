# Shared Types

## Owns

Shared API contracts and language-neutral types used across applications.

## Put here

Stable request, response, product-catalog, and event shapes shared by the
company website, platform API, or product applications.

## Do not put here

Database models, UI components, endpoint implementations, or types used by
only one application.

## Stop here

Add a type only after the contract is shared across an application boundary.
Keep private implementation types in the owning app.
