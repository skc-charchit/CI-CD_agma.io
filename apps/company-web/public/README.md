# Public Assets

## Owns

Files in this directory are served directly to visitors by the company web
application.

## Put here

The homepage entry file, images, fonts, icons, favicon files, and other assets
that do not require a build step.

## Do not put here

Reusable components, API clients, business logic, secrets, or product backend
code. Put interactive source in `../src` and server behavior in `apps/api`.

## Stop here

Keep files browser-ready and static. Stop before adding application logic or
product-specific implementation.
